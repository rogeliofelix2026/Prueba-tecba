# QA — Quality Assurance

## Trabajo del área

El área de **QA** será responsable de planificar y realizar las actividades de aseguramiento de calidad del **Sistema de Gestión Inteligente**, verificando que el MVP cumpla con los requisitos funcionales definidos y que el flujo completo pueda ser utilizado correctamente.

## Actividades principales

* Analizar los requisitos y funcionalidades del MVP.
* Identificar escenarios de prueba.
* Diseñar y documentar casos de prueba.
* Validar el flujo principal de usuario **End-to-End**.
* Realizar pruebas funcionales y exploratorias.
* Realizar pruebas negativas y de validación de errores.
* Validar datos, ubicación y resultados mostrados en el mapa.
* Verificar la integración de las diferentes fuentes de información.
* Validar que la información presentada tenga correspondencia con sus fuentes.
* Verificar el comportamiento de la consulta y respuesta de IA.
* Registrar y realizar seguimiento de defectos.
* Generar evidencias de las pruebas realizadas.
* Realizar pruebas de regresión sobre las funcionalidades modificadas.

## Alcance inicial de pruebas

El testing estará orientado principalmente al flujo:

**Consulta → Actividad + ubicación → Procesamiento → Respuesta contextualizada → Trámites / requisitos / documentación → Información territorial → Mapa → Fuentes → Consultas posteriores**

## Entregables

Dentro de esta carpeta se documentarán progresivamente:

* Casos de prueba.
* Escenarios de prueba.
* Matriz de trazabilidad.
* Evidencias de testing.
* Registro de defectos.
* Reportes de ejecución.
* Informe de resultados del MVP.

## Objetivo

Aportar evidencia sobre la calidad y el correcto funcionamiento del MVP, verificando especialmente la **integración de información, consistencia de datos, ubicación, mapa, fuentes y flujo End-to-End**.
